# PA3 · Варіант 13 · Текстурування

Третя практична робота, створена **від гілки PA2**: та сама поверхня Ruled Rotor Cylinder (Ruled Rotor Cylindroid), Phong shading та нормалі Facet Area Weighted Average. JavaScript і WebGL 1.0, без Three.js.

**Варіант 13: Gram–Schmidt з пріоритетом дотичної T.**

## Запуск

Відкрийте **index.html** у Chrome, Edge або Firefox. Пакети й інтернет не потрібні: три PNG також вбудовані як data URL у TextureData.js, тому текстури працюють через file://.

Необов’язковий локальний сервер:

```sh
node tools/serve.cjs
```

Адреса: <http://127.0.0.1:8765>.

## Що реалізовано

- Три окремі текстури 512 × 512: **diffuse** модулює розсіяну складову, **specular** — дзеркальну, **normal** містить нормалі кожного texel у дотичному просторі.
- Власний безшовний матеріал: бірюзова глазур, мідна облямівка й заглиблені штрихи. Усі карти узгоджені за UV; normal отримана з похідних однієї карти висот.
- Нормалізація T, вилучення проєкції N на T, нормалізація N, B = N × T. Ортогоналізація відбувається **у фрагментному шейдері після інтерполяції**.
- Дотична обчислюється як аналітична похідна Pu. Нормалі успадковано з PA2: сума ненормалізованих векторних добутків суміжних граней.
- UV = (u / 2π, (v − vMin) / (vMax − vMin)); окремі копії вершин на s=0 та s=1 усувають інтерполяцію через увесь атлас. Позиції, нормалі й дотичні цих копій однакові.
- Три sampler2D у texture units 0/1/2; REPEAT, білінійна фільтрація та mipmaps.
- Окреме вимкнення кожної карти, сила рельєфу, повтори u/v та перегляд кожної карти без освітлення.
- З PA2 збережено два повзунки щільності, параметри поверхні, точкове світло на орбіті, паузу, перемикачі Ambient/Diffuse/Specular, каркас U/V, обертання мишею та збереження PNG.

Normal mapping змінює освітлення, **не геометрію чи силует**. Вимкнення normal map або сила 0 повертають гладку нормаль ортогоналізованого базису; вимкнення diffuse/specular повертає сталі коефіцієнти матеріалу. Режими перегляду карт показують вихідні RGB незалежно від перемикачів карт.

## Основні формули

```text
T = normalize(Pu)
N' = normalize(N − T · dot(N, T))  // T має пріоритет
B = normalize(N' × T)
n = normalize((2 · normalMap.rgb − 1) · (strength, strength, 1))
Npixel = normalize(mat3(T, B, N') · n)
I = Ambient + diffuseMap · Diffuse + specularMap · Specular
```

Освітлення та базис обчислюються в координатах спостерігача. Для зворотного боку відкритої поверхні Npixel інвертується. Normal map використовує +Y у напрямку +v; рядок 0 PNG завантажується як v=0 без UNPACK_FLIP_Y_WEBGL. Див. [технічний опис](docs/geometry.md).

## Поверхня з PA1/PA2

```text
x(u,v) = (a + b sin(nu)) cos(u) − v sin(u)
y(u,v) = (a + b sin(nu)) sin(u) + v cos(u)
z(u,v) = b cos(nu),  0 ≤ u ≤ 2π
```

Типово a=1, b=2, n=2, −1.5 ≤ v ≤ 1.5. **13 — номер варіанта; n — параметр поверхні.**

Сітка 96 × 20: **2037 GPU-вершин, 3840 трикутників, 11520 індексів**. 21 додаткова вершина порівняно з PA2 потрібна для UV-шва. Максимум 256 × 80: 20817 вершин, індекси Uint16.

## Перевірка

```sh
node tools/check.cjs
```

Перевіряються формули, ваги площ, орієнтація нормалей, UV-шов, аналітична дотична через незалежну чисельну похідну, вироджені точки, одиничні вектори, крайні щільності та межі чотирьох атрибутних буферів.

Для відтворення текстур:

```sh
node tools/generate-textures.cjs
```

У браузері перевірено компіляцію шейдерів, три texture units, окремий внесок усіх карт, силу 0, режими карт, повтори, керування та мобільний вигляд. Контрольний GPU-приклад із неперпендикулярними T і N підтвердив пріоритет **T**. Вихідний PA2 збережено у своїй гілці.
