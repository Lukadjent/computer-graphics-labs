# CGW · Варіант 13 · Масштабування текстури

Розрахунково-графічна робота **Operations on texture coordinates**, створена від гілки **PA3**. Для непарного варіанта 13 реалізовано масштабування текстурних координат навколо заданої точки. Поверхня Ruled Rotor Cylinder, три карти матеріалу, Phong та Gram–Schmidt з пріоритетом дотичної успадковані з PA3.

## Запуск

Відкрийте **index.html** у Chrome, Edge або Firefox. Інтернет і встановлення пакетів не потрібні. Карти вбудовані у TextureData.js, тому застосунок працює через file://.

Необов’язковий сервер: `node tools/serve.cjs`, адреса <http://127.0.0.1:8765>.

## Керування

| Елемент | Дія |
| --- | --- |
| Масштаб координат s / t | Коефіцієнти від 0.25 до 4; 1 відповідає PA3 |
| Однаковий масштаб s / t | Зв’язує обидва коефіцієнти |
| A / D | Зменшення / збільшення s опорної точки |
| S / W | Зменшення / збільшення t опорної точки |
| Shift + WASD | Крок 0.10 замість 0.02 |
| Схема параметрів | Клацання задає опорну точку |
| Опорна s / t | Введення нормованих координат у межах [0, 1] |
| Скинути масштаб і точку | S=(1,1), c=(0.25,0.5) |
| Перетягування мишею | Обертання моделі |
| Коліщатко | Масштаб моделі у вікні, незалежний від масштабу текстури |
| Знімок PNG | Збереження зображення моделі |

Перед WASD клацніть модель або схему параметрів. Під час редагування полів та списків клавіші не переміщують точку. Використовуються фізичні коди клавіш, тому українська розкладка також працює. У напрямку u точка переходить через замкнений шов; у напрямку v зупиняється на межах. Значення s=1 еквівалентне s=0.

Жовтий круглий маркер розміщено в аналітичній точці P(u,v) та показано поверх моделі, зокрема для дальнього боку. Він має сталий екранний розмір і не деформується від масштабування текстури. Його можна вимкнути.

## Перетворення

```text
q = (s,t) = (u/2π, (v−vMin)/(vMax−vMin))
c = (pivotS,pivotT)
S = diag(scaleS,scaleT)
q′ = c + S(q−c)
st = q′ · TextureRepeat
```

У шейдері використана тотожна форма `q′ = q + (q−c)·(scale−1)`: вона точно повертає q при коефіцієнтах 1, без похибки від операцій c+(q−c). При q=c завжди q′=c. Точка задана в області поверхні **до** повторів PA3. Зміна масштабу зберігає значення st у цій точці; зміна самої точки при S≠1 змінює фазу візерунка.

Збільшення коефіцієнта координат дає більше повторів, тому видимі елементи текстури стають дрібнішими. Diffuse, specular та normal вибираються за одними st. Положення вершин, силует, індекси й нормалі геометрії не змінюються. Додатне діагональне перетворення зберігає напрями T і B; normal mapping використовує базис PA3.

За довільного масштабу на замкненому u-шві може бути стрибок візерунка. Для періодичності потрібне ціле `repeatU × scaleU`. Це властивість перетворених координат; UV-копії вершин і геометричні нормалі на шві залишаються узгодженими. Від’ємний масштаб та обертання не входять до цього варіанта.

## Перевірка

`node tools/check.cjs` перевіряє успадковану геометрію. Типова сітка: 2037 вершин, 3840 трикутників, 11520 індексів; максимальна 256 × 80 має 20817 вершин і 40960 трикутників.

Додатково в браузері перевірено фактичний шейдер на незалежній текстурі з кодованими координатами: незмінність вибірки в c, різні масштаби осей, від’ємні проміжні координати й REPEAT. Перевірено всі напрями WASD, Shift, перехід через u-шов, межі v, фокус полів, неправильне введення, вибір точки на схемі, окремий внесок трьох карт, максимальну сітку, PNG та мобільне компонування. Помилок JavaScript або WebGL не виявлено.
