# PA2 · Варіант 13 · Освітлення

Практична робота № 2 на основі PA1: Ruled Rotor Cylinder (у довіднику — Ruled Rotor Cylindroid), JavaScript та WebGL 1.0.

**Варіант 13:** Phong shading; нормалі вершин — **Facet Area Weighted Average**.

## Запуск

Відкрийте **index.html** у Chrome, Edge або Firefox. Встановлення пакетів та інтернет не потрібні.

За потреби локальний сервер:

```sh
node tools/serve.cjs
```

Адреса: <http://127.0.0.1:8765>.

## Реалізація

- Заповнені трикутники: VBO позицій та нормалей, індексний буфер `Uint16Array`, `gl.drawElements(gl.TRIANGLES, ...)`.
- Два повзунки деталізації за u та v; після зміни перебудовуються геометрія й нормалі.
- Нормаль вершини — нормалізована сума нормалей суміжних граней із вагами їхніх площ.
- Phong shading: позиції та нормалі інтерполюються; Ambient + Diffuse + Specular обчислюються у фрагментному шейдері.
- Одне точкове джерело обертається по колу навколо поверхні. Його координати передаються через uniform після множення на ModelView.
- Ортографічна проєкція, обертання мишею або дотиком, масштабування коліщатком.
- Пауза, положення й швидкість світла, блиск матеріалу та перемикачі складових освітлення.
- Режими поверхні, каркаса U/V та їх накладання; збереження PNG.

## Поверхня з PA1

```text
x(u,v) = (a + b sin(nu)) cos(u) - v sin(u)
y(u,v) = (a + b sin(nu)) sin(u) + v cos(u)
z(u,v) = b cos(nu)
0 <= u < 2*pi
```

За замовчуванням `a = 1, b = 2, n = 2, -1.5 <= v <= 1.5`. Параметри a, b, n відповідають рис. 2 довідника; межі v вибрано для скінченного фрагмента. **13 — номер варіанта; n — параметр формули.** Ціле n забезпечує періодичність за u.

## Структура

| Файл | Призначення |
| --- | --- |
| `Model.js` | Формули, спільні вершини, індекси, нормалі з вагами площ, GPU-буфери |
| `main.js` | WebGL, матриці, керування та анімація точкового світла |
| `shader.gpu` | Вершинний і фрагментний шейдери Phong |
| `index.html`, `styles.css` | Інтерфейс |
| `Utils/m4.js`, `Utils/trackball-rotator.js` | Матриці та обертання з навчального каркаса |
| `docs/geometry.md` | Технічний опис сітки й освітлення |
| `tools/check.cjs` | Перевірки геометрії, нормалей та індексованого малювання |
| `output/PA2_variant13_full.png` | Знімок програми |
| `output/PA2_variant13_surface.png` | Освітлена поверхня |
| `output/PA2_variant13_mesh.png` | Розріджена сітка U/V на поверхні |

Для стандартної сітки 96 × 20: **2016 спільних вершин, 3840 трикутників, 11520 індексів**. На замиканні u вершини спільні, тому нормалі враховують грані з обох боків шва.

## Перевірка

```sh
node tools/check.cjs
```

Перевіряються формули, індекси, суміжність на шві, одинична довжина та орієнтація нормалей, ваги площ на двох гранях різної площі, крайні щільності сітки й межі `drawElements`.
