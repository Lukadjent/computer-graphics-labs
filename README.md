# PA1 · Варіант 13 · Ruled Rotor Cylinder

Практична робота № 1: каркасне відображення аналітичної поверхні засобами JavaScript і WebGL 1.0.

## Запуск

Відкрийте **index.html** подвійним клацанням у Chrome, Edge або Firefox. Встановлення пакетів та інтернет не потрібні.

Якщо запускаєте через VS Code, можна використовувати Live Server. Ще один спосіб за наявності встановленого Node.js:

```sh
node tools/serve.cjs
```

Після цього відкрийте <http://127.0.0.1:8765>.

## Що зроблено

- Окремий `Model.js` з об’єктом `Model`.
- Параметрична поверхня варіанта 13 за формулами з довідника.
- Дві окремі сім’ї поліліній: U бірюзового кольору, V пісочного кольору.
- Окремі буфери вершин U та V й окремий `gl.LINE_STRIP` для кожної полілінії.
- Обертання мишею або пальцем, масштабування коліщатком, скидання камери.
- Зміна параметрів і щільності сітки, перемикання сімей, збереження PNG.
- Знімки екрана в `output/` і технічний опис у `docs/geometry.md`.

## Формули з методички

S. N. Krivoshapko, V. N. Ivanov. *Encyclopedia of Analytical Surfaces*. Springer, 2015. Розділ **Ruled Rotor Cylindroid**, с. **80** книги, **109-та сторінка PDF**.

У завданні використовується скорочена назва Ruled Rotor Cylinder; у книзі відповідна поверхня називається Ruled Rotor Cylindroid.

```text
x(u,v) = (a + b sin(nu)) cos(u) - v sin(u)
y(u,v) = (a + b sin(nu)) sin(u) + v cos(u)
z(u,v) = b cos(nu)
0 <= u <= 2*pi
```

Межі `v` вибираються для скінченного фрагмента зображення: нескінченну пряму неможливо повністю вмістити на екрані. За замовчуванням `a = 1`, `b = 2`, `n = 2`, `-1.5 <= v <= 1.5`. Значення `a`, `b`, `n` відповідають рис. 2 методички; діапазон `v` вибрано для наочності. Для рис. 3 діапазон `v` також вибрано самостійно. Приклад рис. 1 використовує вказані у книзі `0 <= v <= 2`.

Тут U-крива означає **зміну u за сталого v**, а V-крива - **зміну v за сталого u**. За фіксованого u координати лінійно залежать від v, тому V-лінії прямі та паралельні площині xOy.

В інтерфейсі `n` обмежено цілими значеннями 1…8: це гарантує замикання на інтервалі u = 0…2π. Для нецілого раціонального n загалом знадобився б інший період. **13 - номер варіанта, а не значення n.**

## Як влаштовано проєкт

| Файл | Призначення |
| --- | --- |
| `index.html` | Сторінка, елементи керування та порядок завантаження скриптів |
| `Model.js` | Формули, генерація вершин, діапазони поліліній, GPU-буфери та малювання |
| `main.js` | Ініціалізація WebGL, камера, матриці, обробники інтерфейсу |
| `shader.gpu` | Вершинний і фрагментний шейдери з навчального каркаса |
| `Utils/m4.js` | Математика матриць із навчального каркаса |
| `Utils/trackball-rotator.js` | Обертання мишею та дотиком із навчального каркаса |
| `styles.css` | Оформлення сторінки |
| `tools/check.cjs` | Перевірки формул, геометричних властивостей і діапазонів малювання |
| `docs/geometry.md` | Параметризація поверхні, структура даних і алгоритм малювання |
| `output/PA1_variant13_full.png` | Знімок усієї програми |
| `output/PA1_variant13_surface.png` | Знімок самої поверхні |
| `output/PA1_variant13_U.png`, `output/PA1_variant13_V.png` | Кожна сім’я окремо |

Проєкт базується на навчальному каркасі [ademch/WebGL](https://github.com/ademch/WebGL). Збережено його `m4.js`, `trackball-rotator.js`, `shader.gpu` та ліцензію; `main.js` перероблено, `Model` винесено в окремий файл. Геометрія будується безпосередньо у WebGL, без Three.js.

## Перевірка

```sh
node tools/check.cjs
```

Перевіряються опорні точки формул, замикання U-кривих, прямолінійність V-ліній, відсутність нечислових координат, обробка неправильних параметрів, діапазони та окремі виклики LINE_STRIP.
