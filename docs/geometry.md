# Сітка, нормалі та освітлення PA2

## Параметризація

Збережено поверхню варіанта 13 з PA1:

```text
P(u,v) = ((a+b*sin(n*u))*cos(u)-v*sin(u),
          (a+b*sin(n*u))*sin(u)+v*cos(u),
          b*cos(n*u))
```

Джерело: *Encyclopedia of Analytical Surfaces*, с. 80 (PDF с. 109). u змінюється на [0, 2π), v — на вибраному скінченному відрізку. У програмі n ціле.

## Індексована сітка

Для nu кроків за u та nv кроків за v створюється nu × (nv+1) вершин. Порядок — рядки за v, усередині рядка зростає u:

```text
vertex(i,j) = j*nu + i
a = j*nu+i               b = j*nu+(i+1)%nu
c = a+nu                d = b+nu
triangles: (a,b,c), (b,d,c)
```

Два трикутники кожної комірки мають узгоджений обхід. Оператор % замикає останній стовпець на перший. Окрема копія u=2π не створюється; за v поверхня відкрита. Самоперетини поверхні не об’єднуються в одну топологічну вершину.

| Масив | Тип | Дані |
| --- | --- | --- |
| positions | Float32Array | x,y,z кожної спільної вершини |
| normals | Float32Array | nx,ny,nz кожної спільної вершини |
| indices | Uint16Array | Три індекси на трикутник |
| wireIndices | Uint16Array | Пари індексів ребер параметричної сітки U/V |

За 96 × 20 маємо 2016 вершин, 3840 трикутників, 11520 індексів. Позиції й нормалі займають по 24192 байти, індекси трикутників — 23040 байтів. Додатковий каркас U/V має 7872 індекси, або 15744 байти. Діагоналі комірок у цьому допоміжному каркасі не відображаються.

Максимум 256 × 80 дає 20736 вершин, тому всі індекси вміщуються в Uint16 без розширення OES_element_index_uint.

## Facet Area Weighted Average

Для трикутника з вершинами A, B, C:

```text
F = (B-A) × (C-A)
|F| = 2*Area
Nvertex = normalize(Σ Fadjacent)
```

Вектор F додається до накопичувача кожної з трьох вершин трикутника. **До підсумовування F не нормалізується:** інакше втратиться вага площі й утвориться звичайне усереднення граней. Нормалізація виконується лише після обробки всіх суміжних трикутників.

Вершини на u-шві спільні, тому беруть участь у гранях з обох його боків. На відкритих краях v враховуються лише наявні сусіди. Нульові грані не додають внеску. Якщо сума має майже нульову довжину, використовується (0,0,1), щоб не передати NaN до GPU; у виродженій точці однозначна геометрична нормаль може бути відсутня.

## VBO та малювання

Model створює два ARRAY_BUFFER для позицій і нормалей та два ELEMENT_ARRAY_BUFFER для трикутників і допоміжного каркаса. BufferData завантажує їх через gl.bufferData з STATIC_DRAW. Буфери перебудовуються лише після зміни поверхні або деталізації.

Для заповненої поверхні:

```js
gl.drawElements(gl.TRIANGLES, this.indices.length, gl.UNSIGNED_SHORT, 0);
```

count — число індексів, а останній параметр — зміщення в байтах. Для накладання сітки використовується POLYGON_OFFSET_FILL. Допоміжний каркас показує U/V-ребра через gl.LINES.

## Phong shading

Вершинний шейдер перетворює позицію матрицею ModelView, а нормаль — оберненою транспонованою матрицею її лінійної частини. Позиція та нормаль передаються як varying.

Фрагментний шейдер повторно нормалізує інтерпольовану нормаль N та обчислює:

```text
L = normalize(LightPositionEye - PositionEye)
V = (0,0,1)
DiffuseFactor = max(dot(N,L),0)
R = reflect(-L,N)
SpecularFactor = pow(max(dot(R,V),0), Shininess)
Irgb = Ambient + Diffuse + Specular
```

Дзеркальний внесок обчислюється лише коли dot(N,L)>0. V сталий, оскільки проєкція ортографічна. Інтенсивності та базовий колір матеріалу задані в коді; перемикачі керують трьома внесками. Нормаль зворотного боку інвертується через gl_FrontFacing, відсікання зворотних граней вимкнене: це відкрита тонка поверхня.

Це Phong shading: освітлення розраховується після інтерполяції у фрагментному шейдері.

## Рух світла

```text
LightWorld(t) = (r*cos(angle), r*sin(angle), h)
r = 1.35*sceneRadius, h = 0.45*sceneRadius
angle += angularSpeed*deltaTime
LightEye = ModelView * (LightWorld,1)
```

Світло обертається у світовій системі навколо осі z. Перед надсиланням через uniform його позиція множиться на ту саму ModelView, що й точки поверхні. Це зберігає узгоджені координати під час обертання камери. Анімація використовує requestAnimationFrame і час між кадрами; зміна кута вручну ставить обертання на паузу. Позначка й орбіта є допоміжними примітивами з постійним кольором.
